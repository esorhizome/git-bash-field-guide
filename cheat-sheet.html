Git Bash — cheat sheet

Looking things up is the skill, not cheating. Commit = save point  ·  branch = parallel timeline  ·  push/pull = upload/download save points.

🚨 Panic keys — when stuck, start here

Ctrl+CCancel; get the $ back (NOT “copy” here)
qLeave a scrolling view showing : or (END)
Esc :q! EnterEscape the Vim editor, saving nothing
↑ / TabReplay last command / autocomplete a name
git statusAlways safe — run it and read it

👀 Safe anytime — look, never change

pwd ls git status git log git diff git branch git remote -v

🧭 Getting around (Bash)

pwdWhere am I?
ls / ls -aWhat’s in here? (-a: + hidden files)
cd folder / cd ..Enter folder / go up one level
cd ~ / cd -Go home / go back where I just was
mkdir name / touch nameMake a folder / an empty file
cat fileShow a file’s contents
cp a b / mv a bCopy / move-or-rename
rm file ⚠️Delete — permanent, no Recycle Bin
explorer .Open this folder in File Explorer
clearClean the screen (cosmetic only)

🔁 The everyday loop

git initStart watching this folder (once per project)
git statusWhat do you see, Git? (always safe)
git add file / git add .Box this change / everything, for next save point
git commit -m "caption"Save point!
git diff (--staged)Show unsaved edits (or what’s boxed)
git log --onelineList all save points (q quits)

🌿 Branches (parallel timelines)

git branchList timelines (* = you are here)
git switch -c nameNew timeline + go there
git switch nameMove to a timeline
git merge nameFold that timeline into this one
git branch -d nameDelete a merged timeline
git merge --abortEject from a conflicted merge
git log --oneline --graph --allDraw the timeline map

☁️ Online (GitHub)

git clone URLDownload a whole project, first time
git pushUpload my new save points
git pullDownload + blend in everyone else’s
git push -u origin mainFirst-ever push: upload + remember pairing
git fetchCheck what’s new; change nothing

Team habit: pull before you start, every session.

🛟 Undo & rescue

git restore file ⚠️Discard my edits; back to last save (gone for real)
git restore --staged fileUn-box it; edits untouched (safe)
git commit --amend -m "..."Fix last caption (only if not pushed)
git stash / git stash popDrawer half-done work / take it back out
git revert IDSafe undo: new save point cancelling an old one
git reset --hard ID ⚠️⚠️Erase history back to a save point — destroys work
git reflogDiary of everywhere I’ve been; finds “lost” commits

Panicking? Stop. Run git status. Read it. Copy the project folder in File Explorer as a raw backup — then nothing can get worse.

🎮 Game dev extras

git lfs installTurn on Large File Storage (once per machine)
git lfs track "*.psd"Route file type through LFS (commit .gitattributes)
git rm -r --cached folder/Stop tracking committed junk (stays on disk)
git tag v0.3 + git push --tagsName this save point (e.g. playtest build)
Commit what you create; ignore what the engine generates.
Unity: keep Assets/ Packages/ ProjectSettings/ + all .meta; ignore Library/
Unreal: keep Content/ Config/ Source/ *.uproject; ignore Binaries/ Intermediate/ Saved/ DerivedDataCache/; LFS for .uasset .umap
Godot: keep scenes, scripts, project.godot; ignore .godot/ (v4) / .import/ (v3)
Everyone: one person per binary scene/asset at a time — binaries can’t be merged.

The whole of Git in one line: edit → add → commit → push · pull to get everyone else’s saves.
